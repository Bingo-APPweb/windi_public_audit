P10 · Components
Instalar Componentes A4Desk
⬡ VERA · REGO R1
A4Desk usa contenteditable nativo como base — zero dependências externas para o editor básico. Os componentes abaixo adicionam capacidades avançadas: exportação DOCX, SHA-256 client-side, e renderização PDF institucional. Cada componente tem CDN alternativo para deploy offline.
✒️
TipTap Editor
v2.4.0 · Editor framework
Editor rico extensível. Base do A4Desk v2. Plugins para tabelas, menções, histórico. Integração directa com VERA inline suggestions.
npm install @tiptap/react @tiptap/starter-kit @tiptap/extension-table
Clica para copiar
● npm / yarn · CDN disponível
📘
docx (npm)
v8.5.0 · DOCX generation
Geração de ficheiros Word (.docx) no backend. Usado pelo endpoint /enterprise/docs/export/docx. Suporta estilos, tabelas, headers institucionais.
pip install python-docx
Backend Python · Clica para copiar
● pip · Python backend
📕
Playwright
v1.44 · PDF export
Renderiza A4 HTML para PDF institucional. Qualidade de impressão, margens exactas, headers/footers. Usado no endpoint /enterprise/docs/export/pdf.
pip install playwright && python -m playwright install chromium
Backend Python · Clica para copiar
● pip · ~200MB chromium
🔐
Web Crypto API
Built-in · SHA-256 client-side
SHA-256 nativo no browser — zero dependências. Já integrado no A4Desk editor. Garante que o hash é computado no dispositivo do officer, nunca no servidor.
// Já disponível — crypto.subtle.digest('SHA-256', data)
Nenhuma instalação necessária
✓ Pronto · Built-in browser
📖
Mammoth.js
v1.7 · DOCX → HTML reader
Lê ficheiros DOCX uploaded e converte para HTML editável no A4Desk. Permite importar documentos Word existentes para revisão e reselagem com VERA.
npm install mammoth
Frontend JS · Clica para copiar
● npm · CDN: cdnjs.cloudflare.com
🎬
FFmpeg.wasm
v0.12 · Video processing
Processa vídeo no browser — thumbnails, metadata extraction, hash de conteúdo. Usa W-VD-CUT-001 (:8128) no backend para processamento pesado. WASM para client-side light ops.
npm install @ffmpeg/ffmpeg @ffmpeg/util
Frontend JS · Clica para copiar
● npm · ~31MB WASM
🖼️
Sharp
v0.33 · Image processing
Backend Node.js para processamento de imagens. Resize, convert, thumbnail generation para o file manager. Usado também para gerar ícones SVG→PNG no pitch deck generator.
npm install sharp
Backend Node.js · Clica para copiar
● npm · Node backend
