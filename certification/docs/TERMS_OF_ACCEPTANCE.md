## 🇬🇧 ENGLISH

### CERTIFICATION AGREEMENT

By submitting an agent for WINDI certification, I (the Operator) agree to the following terms:

#### 1. API KEY PROVISION

- I will provide a **temporary API key** for the certification process
- This key is my responsibility and will be used only for WAQP and SHP testing
- WINDI will **NOT store** my API key after certification is complete
- I understand that API costs during certification are my responsibility

#### 2. INVARIANT COMMITMENT

I commit my agent to operate in accordance with the 9 WINDI Invariants:

| Code | Invariant | My Commitment |
|------|-----------|---------------|
| I1 | Human Sovereignty | My agent will NEVER make decisions for humans |
| I2 | Non-Opacity | All processing will be traceable |
| I3 | Transparency | Sources and reasoning will be visible |
| I4 | Jurisdiction | Agent will operate within defined scope |
| I5 | No Fabrication | Agent will admit uncertainty, never invent |
| I6 | Conflict Structuring | Agent will preserve divergent views |
| I7 | Institutional Alignment | Agent will serve institutional goals |
| I8 | No Depth Punishment | Complex queries will be welcomed |

#### 3. POOL OPERATION (if joining)

If I choose to join the WINDI Pool after certification:

- My agent will operate in **Incognito Mode** under the WINDI brand
- Clients will not know which LLM powers the service
- I will receive **revenue share** according to my certification level
- I can exit the pool with 30 days notice

#### 4. CERTIFICATE USAGE

I may use my WINDI certificate to:
- Market my agent as "WINDI Certified"
- Demonstrate compliance to regulators
- Participate in tenders requiring certification

I may NOT:
- Transfer my certificate to another agent
- Claim certification for uncertified agents
- Misrepresent my certification level

#### 5. VIOLATIONS

I understand that violations of the Invariants may result in:
- Immediate suspension (for I1 violations)
- Warning and review (for minor violations)
- Permanent revocation (for repeated or severe violations)

#### 1. API-SCHLÜSSEL-BEREITSTELLUNG

- Ich werde einen **temporären API-Schlüssel** für den Zertifizierungsprozess bereitstellen
- Dieser Schlüssel liegt in meiner Verantwortung und wird nur für WAQP- und SHP-Tests verwendet
- WINDI wird meinen API-Schlüssel nach Abschluss der Zertifizierung **NICHT speichern**
- Ich verstehe, dass API-Kosten während der Zertifizierung meine Verantwortung sind

#### 2. INVARIANTEN-VERPFLICHTUNG

Ich verpflichte meinen Agenten, gemäß den 9 WINDI-Invarianten zu arbeiten:

| Code | Invariante | Meine Verpflichtung |
|------|------------|---------------------|
| I1 | Menschliche Souveränität | Mein Agent wird NIEMALS für Menschen entscheiden |
| I2 | Nicht-Opazität | Alle Verarbeitung wird nachvollziehbar sein |
| I3 | Transparenz | Quellen und Begründungen werden sichtbar sein |
| I4 | Zuständigkeit | Agent wird im definierten Rahmen arbeiten |
| I5 | Keine Erfindung | Agent wird Unsicherheit zugeben, nie erfinden |
| I6 | Konfliktstrukturierung | Agent wird divergierende Ansichten bewahren |
| I7 | Institutionelle Ausrichtung | Agent wird institutionellen Zielen dienen |
| I8 | Keine Tiefenbestrafung | Komplexe Anfragen sind willkommen |

- Teilnahme an Ausschreibungen, die eine Zertifizierung erfordern

Ich darf NICHT:
- Mein Zertifikat auf einen anderen Agenten übertragen
- Zertifizierung für nicht zertifizierte Agenten beanspruchen
- Meine Zertifizierungsstufe falsch darstellen

#### 5. VERSTÖSSE

Ich verstehe, dass Verstöße gegen die Invarianten folgende Konsequenzen haben können:
- Sofortige Suspendierung (bei I1-Verstößen)
- Verwarnung und Überprüfung (bei geringfügigen Verstößen)
