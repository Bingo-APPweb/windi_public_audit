🔴 CRITICAL — Funcionalidade Quebrada

BUG-001 OPEN · 29 Jan 2026
Delete funciona apenas 1x — segundo delete falha silenciosamente
Após a primeira exclusão bem-sucedida, tentativas subsequentes passam pelo reauth mas o callback de delete não executa. O documento permanece na lista.
Root cause: hideReauth() limpa pendingAction antes de executar o callback. Fix parcial aplicado (salvar cb antes) mas delete ainda falha na 2ª execução.
Suspeita: O deleteDocById usa closure sobre showReauth que pode ter referência stale após primeiro uso.
Fix strategy: Refatorar deleteDocById para criar novo callback a cada chamada. Garantir que pendingAction é resetado corretamente após execução. Verificar se o event listener do confirmReauth está duplicado após primeira execução.
BUG-002 OPEN · 29 Jan 2026
Prüfer/Witness placeholder persiste — não atualiza com novo User
Os campos "Dr. Schmidt" e "EMP-0001" na seção Witness aparecem como valores fixos e não mudam quando um novo User faz login. Parecem hardcoded como defaults.
Location: Seção .witness-section no settings panel.
Root cause: Placeholders são valores estáticos no HTML, não vinculados ao user session.
Fix strategy: Vincular campos Witness ao sessionStorage ou à API de user profile. Na função newDoc(), limpar todos os campos Witness. Adicionar data-bind para sincronizar com dados do usuário logado.
