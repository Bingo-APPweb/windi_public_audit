### Concept

- WINDI insiders see: the entire system presenting itself in real-time

Same object. Two readings. Governança silenciosa in its purest form.

| **LivingOrb** | Glowing ambient light | Cognitive Score (89/100) — breath depth = health | HTML5 Canvas, 60fps |

| **SovereigntyGauge** | Elegant green/amber bar | Architecture ratio 93/7 (42 local, 3 LLM) | CSS + dynamic data |

### Living Behaviour
- **Orb breathing rate:** healthier = calmer, stressed = faster
- **Orb pupil:** inner bright point reacts to confidence level
- **Nerve particles:** flowing = healthy, stopped = service down
- **Neural connections:** lines between particles = wiring topology
- **Sovereignty bar:** green = local sovereign, amber = LLM dependency

### Progressive Disclosure
- Default: ambient elements, no text, no numbers
- Click: expanded panels with full data (CogPanel, PulsePanel, SovPanel)
- Click outside: collapse back to ambient
- Never blinks. Never intrudes. Always present.
