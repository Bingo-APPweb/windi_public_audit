## 2. Problema

O Dragon Chat (:8108 via :8112) declarava 3 tiers (FREE/MED/HIGH) mas comportava-se como se tivesse 1:
- MED e HIGH ambos chamavam o orquestrador
- O orquestrador usa apenas Claude (Anthropic)
- MED fazia fallback silencioso para HIGH

**Violação I14:** O sistema afirmava uma capacidade que não tinha.
