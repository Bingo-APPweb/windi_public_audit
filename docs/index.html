Zero-Knowledge Principle
Data Stays with Client
SGE runs at the edge. WINDI Core receives ONLY: hash + categories + metadata + decision. ZERO sensitive data. Client holds data, WINDI holds proof of virtue.
Dual Hash Architecture
content_hash + bundle_hash
Two integrity seals per document: content_hash computed from document blocks, bundle_hash from final exported bytes. Viewer verifies raw bytes before unzip.
Virtue Receipt
Proof of Governance
Hash + categories (type, impact, domain, value_range R1-R5) + governance (SGE score, risk, validation) + decision (action, role, timestamp, AI rec, override) + flags.
