## Erfolg

### Wann ist der Pilot erfolgreich?

Der Test ist erfolgreich, wenn:

1. **Kundenwünsche ankommen.** Wenn jemand anruft und niemand Zeit hat, geht der Wunsch trotzdem nicht verloren.

2. **Vorgänge sind brauchbar.** Die erstellten Vorgänge enthalten genug Information, um sinnvoll weiterarbeiten zu können.

3. **Menschen bleiben verantwortlich.** Das System übergibt — der Mensch entscheidet und schließt ab.

4. **Nichts wird falsch versprochen.** Das System macht keine Zusagen, die Menschen dann nicht einhalten können.

### Erfolgskriterien (Vorschlag)

| Kriterium | Bedeutung |
|-----------|-----------|
| Anruf verstanden | System versucht zu erkennen, worum es geht |
| Daten erfasst | Name, Kontakt, Anliegen vorhanden |
| Vorgang erstellt | Zuständige Person kann weiterarbeiten |
| Erfassung ≠ Bestätigung | Der Vorgang hält fest, was erfasst wurde — nicht, dass jede Angabe richtig ist |
| Kein Fehlversprechen | Keine automatischen Zusagen |
| Rückruf möglich | Kunde kann kontaktiert werden |

## Abbruch

### Wann beenden wir den Pilot?

Der Test kann jederzeit beendet werden — ohne Begründung nötig.

Mögliche Gründe:

- **Keine Zeit.** Der Test passt gerade nicht in den Alltag.
- **Funktioniert nicht.** Das System versteht Anrufer nicht gut genug.
- **Verursacht Mehrarbeit.** Statt zu helfen, macht es mehr Aufwand.
- **Vertrauen fehlt.** Es fühlt sich nicht richtig an.

### Was passiert beim Abbruch?

1. Der Pilot wird beendet und die Testnummer nicht weiter für den Test genutzt.
2. Neue Anrufe werden nicht mehr angenommen.
3. Bestehende Vorgänge bleiben erhalten (zur Nachbearbeitung).
4. Eure bestehende Telefonie ist davon nicht betroffen.

### Wer kann den Pilot stoppen?

Jeder aus der Familie / dem Team. Keine Genehmigung nötig.

## Human Handoff

### Wann übernimmt ein Mensch?

**Immer.** Das System erstellt Vorgänge — Menschen schließen sie ab.

Zusätzlich gibt es Situationen, in denen das System an menschliche Bearbeitung übergibt:

| Situation | Reaktion |
|-----------|----------|
| Kunde ist verärgert | Rückruf / menschliche Übernahme |
| Dringendes Anliegen | Rückruf / menschliche Übernahme |
| System versteht nicht | Rückruf / menschliche Übernahme |
| Kunde fragt nach „echtem Menschen" | Rückruf / menschliche Übernahme |

### Was das System niemals tut

- Entscheidungen treffen
- Bestellungen ändern
- Geld erstatten
- Termine verbindlich zusagen
- Preise verbindlich festlegen oder verhandeln
- Lieferversprechen geben

**Der Mensch bleibt verantwortlich. Das System ist nur ein Werkzeug.**
