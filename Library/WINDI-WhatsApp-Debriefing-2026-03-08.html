01 · O que o WhatsApp está fazendo
Mudança histórica: O WhatsApp está substituindo o número de telefone como identificador primário. A partir de junho 2026, o campo to/from nos webhooks pode ser um BSUID — não mais um número E.164. Quem não atualizar vai quebrar silenciosamente.
📱 Username — o que é
Cada usuário poderá ter um handle único (ex: @joberdragon). Voz, vídeo e chat funcionarão via username — sem revelar número. Opcional para usuários, obrigatório que empresas suportem.

04 · Especificação Patch v1.1.0 — BSUID Ready
🔧 Função universal de detecção de ID
def detect_wa_id_type(recipient: str) -> dict: """ Detecta automaticamente o tipo de identificador WhatsApp. Retorna {"type": "phone"|"bsuid"|"username", "value": ...} """ import re r = recipient.strip() # E.164 phone number if re.match(r'^\+\d{7,15}', r): return {"type": "phone", "value": r} # BSUID (formato Meta: 2-letter country + 128 alphanumeric) if re.match(r'^[A-Z]{2}_[A-Za-z0-9]{10,128}', r): return {"type": "bsuid", "value": r} # Username handle if r.startswith('@'): return {"type": "username", "value": r} # Fallback: tratar como número sem + return {"type": "phone", "value": r} def resolve_wa_recipient(recipient: str) -> str: """ Normaliza qualquer identificador para uso no payload Meta API. BSUID e username vão direto. Número: garantir formato E.164. """ info = detect_wa_id_type(recipient) if info["type"] == "phone": v = info["value"] return v if v.startswith('+') else '+' + v return info["value"] # BSUID ou @username passam direto

05 · Vantagem estratégica WINDI
🛡️ Invariante Constitucional já protege
I11 (Permanência de Evidência Criptográfica) — cada envio de mídia é selado no Ledger com hash SHA-256 do destinatário. Quando o BSUID substituir o número, o hash muda de objeto mas a lógica de governança é idêntica. Zero refactor constitucional.
🏗️ DID WINDI = WhatsApp username nativo
O DID cycle WINDI (Ed25519 + UUIDv7) já gera identidade soberana sem número. O username WhatsApp será simplesmente mais um handle desse DID — não uma dependência nova, mas uma extensão da arquitetura existente.

O deadline Meta é junho 2026. A maioria das empresas ainda usa telefone como chave primária nos seus CRMs — e vai quebrar. A WINDI estará com BSUID totalmente integrado em março, 90 dias à frente. Isso é posição de pioneiro, não de seguidor.
