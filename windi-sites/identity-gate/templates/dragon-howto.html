Dragon Shadow Forest Guide

🔮 What is Dragon Shadow Forest?

Dragon Shadow Forest encodes SHA-256 hashes as a 16×16 grid of invisible dragon glyphs. Each glyph represents one bit of the hash — creating a visual fingerprint that can be embedded in documents for forensic verification.

Dark Dragon
bit = 1
Shadow Dragon
bit = 0
I9 Human Gate I11 Ledger Seal I14 No Placeholders

💻 Using the Dashboard

1
Open the Dashboard
Navigate to /law/dragon/ or click 🐉 Dragon Forest in the WINDI-SITES workspace sidebar.
2
Enter Content
Type or paste your document text into the content field. This can be any text — contracts, certificates, legal documents.
3
Choose Ledger Registration
Enable "Register with Ledger" if you want a permanent, verifiable receipt (I11). Leave unchecked for preview only.
4
Click Encode
The system computes the SHA-256 hash and renders 256 dragon glyphs. You'll receive a Receipt ID and can view the grid.
5
Verify Later
Use the Receipt ID to verify the document at any time via /dragon/verify/{receipt_id} or Verify Public.

🔌 API Reference

For programmatic access, use these endpoints:

Method Endpoint Description
GET /dragon/health Module status and info
POST /dragon/encode Encode content → SVG + Receipt
POST /dragon/encode-pdf Encode PDF with dragon overlay
POST /dragon/preview Preview only (no Ledger)
GET /dragon/verify/{id} Verify receipt with Ledger

Example: Encode via cURL

curl -X POST https://windi-domain.com/law/dragon/encode \
  -H "Content-Type: application/json" \
  -d '{
    "content": "SGVsbG8gV0lOREk=",
    "doc_name": "My Document",
    "register_ledger": true
  }'

Example: Encode PDF

curl -X POST https://windi-domain.com/law/dragon/encode-pdf \
  -F "pdf_file=@contract.pdf" \
  -F "doc_name=Contract 2026" \
  -F "opacity=0.07" \
  -F "return_format=pdf" \
  --output encoded_contract.pdf

📚 Use Cases

1. Legal Document Certification

Embed invisible dragon grids in contracts. If the document is altered, the grid will no longer match — instant tamper detection.

2. Certificate Authentication

Add dragon overlays to certificates and diplomas. Verify authenticity by scanning and comparing with the Ledger.

3. Evidence Preservation

Seal evidence documents with forensic dragon grids. The Receipt ID proves the document existed at a specific time.

4. Brand Protection

Mark official documents with invisible dragons. Counterfeits won't have the matching grid pattern.
